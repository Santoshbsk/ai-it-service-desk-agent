IT SUPPORT RUNBOOK

Title: Password Reset
Document ID: IT-ACCESS-001

Employees who forget their corporate password should use the approved Self-Service Password Reset portal.

Steps:

1. Open the corporate password reset portal.
2. Enter the corporate username.
3. Complete identity verification.
4. Complete MFA verification.
5. Create a new password that meets the corporate password policy.
6. Sign in again using the new password.

Security:
IT Service Desk personnel must never request an employee's password.

Escalation:
If identity verification or MFA fails, escalate the request to the Identity and Access Management team.
